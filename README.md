# SOA Tourism

A **Service-Oriented Architecture (SOA)** tourism web application built with microservices. Team project currently in active development.

---

## About the Project

This is a comprehensive tourism platform where users can register as tourists or guides, create and follow blogs, organize and book tours, and interact with other users.

The system is designed using **microservices architecture** with clear separation of concerns, API Gateway, inter-service communication, and modern DevOps practices.

---

## Team

**Developed by a team of 4 students.**

---

## Technologies & Architecture

### Core Technologies
- **Microservices Architecture (SOA)**
- **Multiple programming languages** (one service must be in **Golang**)
- **Docker** + **Docker Compose**
- **API Gateway**
- **NoSQL databases** (Document + Graph database - Neo4j)
- **REST** and **RPC** communication
- **Saga Pattern** for distributed transactions
- **Tracing, Logging & Monitoring**

### Planned / Implemented Services
- Stakeholders Service
- Blog Service
- Tour Service
- Followers Service
- Purchase Service
- Auth Service (optional)
- API Gateway

---

## Key Features

- User authentication and role management (Tourist, Guide, Admin)
- Blog system with markdown support, likes and comments
- Tour creation with map integration and key points
- Follower system with personalized recommendations
- Reviews and tour execution tracking
- Multi-language backend implementation

## Architecture Highlights

- Distributed tracing and log aggregation
